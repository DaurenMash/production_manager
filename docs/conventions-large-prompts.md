# Соглашения: как передавать большие куски кода ИИ

## Правило

Когда нужно передать ИИ (в чат) большой объём кода:

1. **Вывод команды `Get-Content`/`Get-ChildItem` и других длинных команд — сохраняй в файл в корне проекта**, а не копируй в чат.
2. Имя файла: `_tmp_prompt_<тема>.txt`, например `_tmp_prompt_employees_pages.txt`.
3. Прикрепляй файл в чат как вложение.
4. После использования — можно удалять (в `.gitignore` уже добавлены `note_*.txt` и `data_*.txt`, но эти `_tmp_prompt_*` пока не игнорируются).
