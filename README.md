# ProdMan — Production Manager

Веб-приложение для менеджера производства.

**Задача:** помочь расставить сотрудников по рабочим станциям с учётом их квалификации, а затем рассчитать отработанные часы за месяц (с отдельным учётом ночных часов).

## Быстрый старт

### Требования
- JDK 21+
- Maven 3.9+
- Node.js 20+
- Docker Desktop
