# ProdMan — Production Manager

SaaS-приложение для управления производством. Каждый клиент (организация) получает изолированный личный кабинет и управляет в нём своими сотрудниками, отделами, должностями, рабочими станциями и расписаниями.

**Задача:** помочь менеджеру производства расставить сотрудников по рабочим станциям с учётом квалификации и рассчитать отработанные часы за месяц (с отдельным учётом ночных часов).

## Как это работает

- Клиент регистрируется → получает личный кабинет → работает только со своими данными.
- Все бизнес-сущности привязаны к `tenant_id`. Данные клиентов изолированы (см. ADR-0002).
- Один frontend (SPA) обслуживает всех клиентов; разграничение — по JWT и `tenantId`.
